# Test Product Backlog

This file contains fake PBIs for validating the GitHub Product Backlog automation.

# Sprint 1

## PBI 1: Test Player Movement

### Priority: High

**User Story:**

As a player,  
I want to move my character across the game board,  
so that I can navigate the game environment.

**Acceptance Criteria:**

- Player can move left and right
- Player cannot move outside the game board
- Movement updates the player's position

---

## PBI 2: Test Main Menu

### Priority: Medium

**User Story:**

As a player,  
I want to see a main menu when the game loads,  
so that I can choose how to begin playing.

**Acceptance Criteria:**

- Main menu appears when the game starts
- Menu contains a Start Game button
- Start Game button loads the game

---

# Sprint 2

## PBI 3: Test Enemy Spawn

### Priority: High

**User Story:**

As a player,  
I want enemies to spawn during gameplay,  
so that I have obstacles to overcome.

**Acceptance Criteria:**

- At least one enemy can spawn
- Enemy appears on a valid game tile
- Enemy spawning does not crash the game

---

## PBI 4: Test Score Display

### Priority: Low

**User Story:**

As a player,  
I want my score displayed on the screen,  
so that I can track my progress.

**Acceptance Criteria:**

- Score is visible during gameplay
- Score starts at zero
- Score updates when points are earned

---

# Sprint 3

## PBI 5: Test Save System

### Priority: High

**User Story:**

As a player,  
I want to save my current progress,  
so that I can continue playing later.

**Acceptance Criteria:**

- Player can create a save
- Save contains the current player state
- Existing save can be loaded successfully
